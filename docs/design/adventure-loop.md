# 历练循环（战斗 / 行囊 / 装备 / 功法 / 设置）

依据 `docs/research/idle-xiuxian-systems-2026-09-10.md` 与 ADR-0003。不抄竞品名称与数值。

## 目标与非目标

目标：挂机修炼的同时挂机打怪；回来能在行囊核对收益、穿戴、学功法、突破，再挑战下一关。下一关掉更高品质装备和更高阶技能书。

非目标：服务器、视觉战斗、炼器、多套装配、无限随机怪物种。

## 玩家可观察流程

1. 首次进入：凡人，第一关已选，行囊空，未穿戴，未学功法。
2. 停留或离开：修为按效率涨；当前关按战斗公式结算击杀与掉落。
3. 回来：一次弹窗写修为、击杀摘要、入袋物品；历练页有文字战报。
4. 行囊：格网点开一件才出现对比和穿/锁/弃；装备不够境界不能穿。对比写已穿属性、能不能穿/学、换上或学后的战力变化。
5. 功法：已学加成置顶，未学灰显。对行囊里的技能书点「参悟」，消耗书籍，永久加成；重复学无效。
6. 战力或境界不够时，「挑战下一关」失败并说明缺什么。
7. 够了则进入下一关，掉落表换成更高品质/更高阶。
8. 行囊满：按设置跳过掉落或丢掉未锁定的最低品质，并写进战报。

## 验收标准

- 在线每秒与离线区间用同一套战斗公式；重复打开不重复发同一段掉落。
- 时钟回拨：修为不减，不补发战斗。
- 离线超过上限：修为与战斗都只按上限秒数算。
- 白蓝紫金红装备都能掉、能显示、能穿；五槽互不覆盖错位。
- 黄玄地天功法都能学，高阶书有境界门槛。
- v1 旧档加载后修为境界不变，历练从第一关开始。
- 底栏五页都能进；设置能开关战报、改满包策略、导出存档。
- 原有前三阶突破与离线弹窗文案仍在。

## 状态与公式

配置进 `game/resources/config/adventure.json`，不进存档。

```text
战斗数 = 境界基础 + 已穿装备 + 已学功法
有效伤害 = max(1, 攻 - 敌防 × 0.4)
敌有效伤害 = max(0, 敌攻 - 防 × 0.5)
击杀耗时 = 敌血 / (有效伤害 / 攻击间隔)
阵亡耗时 = 无限（敌有效伤害=0）或 己血 / (敌有效伤害 / 敌间隔)
若 阵亡耗时 ≤ 击杀耗时：本段 0 击杀，记「不敌」
否则 击杀数 = floor(秒数 / (击杀耗时 + 重生间隔))
战力 = 攻 + 防 × 0.8 + 血 × 0.04
```

掉落用存档里的 `loot_seed` 做可重复伪随机，不读系统时钟。表内 `loot_chance_scale`（当前 0.2）乘在每条掉落概率上，用来把满包从「十几分钟必炸」收成「回来整理一次」。

满包策略：

- `skip`：不进袋，计数到 `bag_skipped`
- `discard_lowest`：丢未锁定、未穿戴的最低品质 1 件再进袋；没有可丢则等同 skip

## 存档（schema 2）

`payload` 在原有修为三字段上增加：行囊、容量、下一 uid、穿戴 uid、已学功法、当前关、已解锁关、战报、loot_seed、设置。界面滚动位置不存。

## 明确不做

自动突破、自动穿戴、自动学功法、商店买格、套装收集进度、无限层塔、日次数。
