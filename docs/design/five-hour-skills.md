# 五小时功法方案

目标：功法不再是「学过就永远全开的第二套攻防血」，而要像刚做完的装备一样，在 **5 小时目录** 里产生「留还是转、转哪一门、小成还是等下一本」。

依据：`docs/research/idle-xiuxian-systems-2026-09-10.md`、`docs/research/idle-xiuxian-market-2026-09-10.md`、ADR-0003、`docs/design/five-hour-loop.md`。不抄竞品名称与数值。本篇只谈功法；装备六层已经在 0.1.14。

## 现在功法为什么撑不住时长

表里其实已经按四路写了 16 门（每阶 心法 / 攻 / 体 / 步），但规则把选择抹平了。

| 现状 | 结果 |
| --- | --- |
| 学过的全部生效，没有运转栏 | 第二本残页只是「再加一个数」，没有卸哪门 |
| 步风 / 影步 / 缩地 / 凌空 **没有速度** | 青石涧的缺速墙只能靠鞋，功法帮不上短板 |
| 心法（吐纳 / 凝气 / 周天 / 混元）不加修为效率 | 修仙放置里最常见的「功法改怎么挂」这一条是空的 |
| 功法页是只读名单 | 参悟、小成、对比全在行囊；第四个底栏没有动词 |
| 入门后再交 2 本 = 小成 ×1.4 | 有收集，但仍是「能点就点」，没有栏位冲突 |
| 天阶门槛是筑基中（order 6） | 五小时终点是筑基后，天书可能学得上，和「看得见学不了」对不上 |

装备已经有：合、卸、短板、套装取舍。功法还停在 ADR-0003 的最小切片：「1 个可学项，加可见战斗数」。

## 市场上功法实际在干什么（结构，不抄名）

跨产品重复出现的只有这几条，见系统调研 A8 / A15 / A16 和市场调研 S4 / S9：

1. **改同一组战斗数或改挂机效率，用来过下一道墙。** 不是另开经营。
2. **有栏位或加点，不能十六门同时开。** 神通有上限、天赋要放进栏、战斗技能要解锁行。全开等于没有功法。
3. **心法 / 效率 和 战技分开。** 极简作把功法写成「怎么挂」；有战斗的作把技能写成过图尺子。
4. **用境界或技能点解锁，不要开局铺满。**
5. **独立功法页要能操作**：可学、已学、消耗、加成可见。只展示名单的页留不住人。

明确不搬的（多年体量或越界）：Melvor 整树技能等级、逍遥多套神通方案、IdleOn 多角色天赋、灵根系、技能点岛、主动热键、洞府。

## 仍然不做

服务器、账号、宗门、论剑、付费、炼器、多套装配、视觉战斗、技能点、灵根、主动技、第六个底栏、洞府、大成 / 圆满、用修为升级功法（和突破抢同一条轴）。

参悟入口可以留在行囊，但功法页必须能运转、卸下、看对比。不新开页。

## 要补的五层（都挂在现有功法页 + 行囊弹窗）

16 门 id 不动。只给每门补一个 `role`，并让装配生效。

| 路 | 黄 | 玄 | 地 | 天 | 装配进哪 |
| --- | --- | --- | --- | --- | --- |
| 心法 | 吐纳术 | 凝气诀 | 周天功 | 混元功 | 心法栏 ×1 |
| 攻 | 裂石拳 | 开山掌 | 崩岳拳 | 碎星指 | 战技栏 |
| 体 | 铁骨诀 | 御体诀 | 金钟罩 | 不灭体 | 战技栏 |
| 步 | 步风 | 影步 | 缩地 | 凌空虚度 | 战技栏 |

### 1. 路数生效

```text
心法：修为效率 × (1 + 心法系数 × 等阶)  + 少量攻防血
攻  ：主加攻
体  ：主加防 / 血
步  ：主加速（表里现在缺的就是这条）
等阶：入门 1.0，小成 1.4（沿用 0.1.14）
只有「正在运转」的门进入 CombatRules / cultivate_rate
已学未运转 = 图鉴，不加数
```

心法系数先按「吐纳入门约 ×1.08、小成 ×1.12」量，不要压过回气丹的 ×1.15，两套可以叠，但丹是 10 分钟、心法是常驻。

步法必须写 `speed`。否则青石涧短板和功法仍然无关。

### 2. 运转栏（功法版五槽）

```text
凡人起：心法 1 + 战技 1
炼气圆满（order 4）：战技 +1，共 3 栏
天书仍学不了的前提下，5 小时内不要再加第 4 栏
```

玩家会问：吐纳留在心法栏，还是把裂石换上去过野猪。这是装备「留还是穿」的同一刀。学过的门不必忘，卸下即可。

不是多套方案。同一时间只有这一组在转。

### 3. 短板预览挂到功法

装备弹窗已经写换上后的攻防速。功法弹窗同样写：

```text
此关缺速。运转步风后速 +N，可过墙 / 仍差 N
```

历练提示若缺攻 / 防 / 速，顺带写「可运转一门攻法 / 体法 / 步法」。不要新墙种；用现有短板墙，让功法成为第二条过墙手段。

古碑台可加 **一条功法墙**（目录终点才用）：须运转一门已小成的黄阶，或一门已入门的地阶。用来保证 5 小时内必须做过「小成或换更高阶」，而不是只堆装备。

### 4. 残页仍是消耗，选择改成「小成 vs 下一本」

入门 1 本、小成再 2 本，公式不动。栏位有限之后，黄阶小成和留残页等玄阶会打架：

- 野猪坡：裂石入门就能补攻到 18（凡人 10 + 裂石 8）。先穿高战力剑还是先学裂石，是第一道功法题。
- 炼气后：玄阶开。把 2 本黄阶残页喂小成，还是留格等凝气 / 开山，是第二道。

大成不做进这 5 小时。残页不合并（已可堆叠）。

### 5. 功法页能点

底栏功法页改成和行囊同一套交互密度：

- 顶：已运转 心法 / 战技 1 / 战技 2，空槽可点
- Tab：全部 / 心法 / 攻 / 体 / 步
- 列表：已学置顶，未学灰显，行囊有残页标出来
- 点开：对比、运转、卸下、小成（有残页时）、关闭

参悟第一本仍可在行囊。小成两边都能点。功法页不再是说明书。

## 五小时时间轴（功法这条）

装备轴仍按 `five-hour-loop.md`。下面只写功法必须亲手做的事。终点仍是：筑基后期、古碑台外围、见过天书、**天书还学不了**。

因此天阶 `min_realm_order` 应从 6（筑基中）改到 **8（金丹初期）**。古碑台可以掉天书，学要等金丹。地阶门槛 4（炼气圆满）可留，让 3.5 小时后有一门地阶可入门。

| 墙钟 | 境界大约 | 功法必须做的 |
| ---: | --- | --- |
| 0–20 分 | 凡人 → 炼气初 | 学吐纳并运转（心法，效率第一次变）；功法页能点开 |
| 20–50 分 | 炼气中 | 野猪缺攻：裂石入门运转，或合刀。两套都能过，要选 |
| 50–90 分 | 炼气后 | 青石缺速：步风加的速第一次有用；战技栏只有 1，裂石和步风互挤 |
| 1.5–2.5 时 | 圆满 → 筑基初 | 第二战技栏开；御体 / 铁骨过断魂防墙；玄阶可入门 |
| 2.5–3.5 时 | 筑基中 | 黄阶一门小成，或换成玄阶入门。不能两头都喂满 |
| 3.5–4.5 时 | 筑基中后段 | 地阶入门一门（周天换心法，或崩岳 / 金钟 / 缩地） |
| 4.5–5 时 | 筑基后 | 古碑台功法墙；见天书、点开学不了 |

金丹三阶和天阶入门留给离线尾巴，不计入「五小时试完」。

## 表要改的数字（原则）

- 四路 `role` 写入 `adventure.json`，id 不改。
- 步法补 `speed`：黄约 3.5（凡人 + 步风过青石 3.2）、玄约 6、地约 10、天约 16。具体用现短板表校。
- 心法补 `cultivate_bonus`（入门 / 小成两档），常驻，弱于回气丹峰值。
- 天阶境界锁改到 8。
- 头目层提高「本关主短板对应路数」的残页率，总 `loot_chance_scale` 仍约 0.2。
- 前三阶修为时间仍不动。

## 存档

`schema_version` 升到 4。新增：运转中的心法 id、战技 id 列表。v3 旧档：已学门保持入门 / 小成，**默认不自动运转**；进游戏时若栏空，把最早学的一门心法、一门战技补上，避免老玩家打开战力骤降。也可以第一次进功法页用一行提示：「学过的功法要运转才生效」。

## 分步落地（已落地）

| 步 | 内容 | 玩家立刻感到的 |
| --- | --- | --- |
| F | 步法加速度、心法加效率、弹窗写短板 | 功法第一次能过墙、能改挂机 |
| G | 运转栏 1+1，学过不再全开 | 出现「转哪一门」 |
| H | 炼气圆满开第 2 战技栏；功法页可点、可分类 | 第四个底栏不再是名单 |
| I | 天阶锁到金丹初；古碑台功法墙；头目偏掉对应残页 | 5 小时内必须小成或换阶 |

F 就能验证「不是学了就永远变强」。I 之前不要技能点、灵根、大成。

## 验收（功法目录）

- 不看攻略，按提示能独立完成：学、运转、卸、换路数过短板、小成。
- 野猪坡或青石涧至少有一次「只换装备或只换功法就能过，两套一起更宽」。
- 同一栏里高阶心法在至少一关上不如对路战技（例如青石涧周天不如步风）。
- 5 小时内能见到天书，不能学；90 分钟内不能点进古碑台头目（沿用装备方案）。
- 底栏仍是五页。v3 旧档能进，栏空时有一次温和补位。
