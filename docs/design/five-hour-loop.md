# 五小时试玩方案

目标：一名新玩家从凡人开号，**坐满约 5 小时**才能把当前目录里该见的系统都试一遍，并停在「古碑台外围、见过红装、天书还穿不上」。不是坐到金丹后期（那是 20 小时以上的离线尾巴），也不是把界面点完就算试完。

本篇是 `0.1.14`–`0.1.15` 已落地的 Day 1 目录，不再代表产品终局。当前事实基线为 `0.1.15`、存档 schema 4；Day 7–180 的经营与传承见 ADR-0004、ADR-0005 和 `docs/design/long-term-progression.md`。

依据：`docs/research/idle-xiuxian-systems-2026-09-10.md`、ADR-0003、ADR-0004、ADR-0005、`docs/design/adventure-loop.md`。不抄竞品名称与数值。

## 现在为什么撑不满 5 小时

修为轴其实已经够长：前三阶约 17 分钟，筑基后期突破约 1.7 小时纯在线，金丹初期约 5 小时。缺的是历练轴。

| 现状 | 结果 |
| --- | --- |
| 8 关只看总战力 | 杂木林挂一会儿就能点下一关 |
| 同槽永远穿更高战力 | 行囊没有「留还是穿」 |
| 装备不堆叠、不能合 | 第二把削木剑是垃圾 |
| 词条只是文案 | 弹窗好看，不影响结算 |
| 功法学一次永久 | 残页叠了也没用 |
| 丹药材料不能用 | 分类是空壳 |
| 关卡没有层 | 目录 8 个名字，十几分钟看完 |

5 小时要来自 **墙 × 收集 × 选择**，不是来自第六个底栏。

## 本五小时里程碑不做

服务器、账号、宗门多人玩法、论剑、付费、无限随机重铸、多套装配、视觉战斗、商店买格、无限层塔、日次数、传承、第六个底栏、洞府。

丹药只做「限时服用」，材料只做「温养一次」，都不开炼器页。这里的“本里程碑不做”不禁止 ADR-0005 在后续完整里程碑中增加单机洞府、定向器室和可恢复传承；全局仍禁止 PvP、排行和强制联网。

## 要补的六层（都挂在现有五页上）

### 1. 同名合并

装备仍不进网格堆叠。两件 **同 id、同合阶** 可合成一阶。

```text
合阶 0 → 5
属性 = 表内攻防速血 × (1 + 0.12 × 合阶)
装备战力用同一条公式重算
已穿的不能合，先卸
```

玩家会问：这把现在穿，还是留着和下一件合。重复掉落变成进度。这是 NGU 装备时长的来源，也是我们行囊的第一刀。

### 2. 关卡短板墙

「挑战下一关 / 进入更深一层」不再只看总战力。每关写四道门槛，缺哪条弹窗和历练提示写哪条。

```text
须境界
须战力
须攻  或  须防  或  须速   （每关主短板不同）
```

投放意图：

| 关 | 主短板 | 为什么 |
| --- | --- | --- |
| 杂木林 | 几乎无 | 教穿、教合 |
| 野猪坡 | 攻 | 皮厚，破不开 |
| 青石涧 | 速 | 出手快，打不着节奏 |
| 雾鸦岗 | 速 + 攻 | 又飘又啄 |
| 断魂谷 | 防 / 血 | 挨打疼 |
| 赤焰岭 | 攻 | 要破火皮 |
| 沉渊泽 | 防 + 速 | 又肉又黏 |
| 古碑台 | 三短板都抬 | 五小时终点墙 |

高攻断魂刃在青石涧可能不如合过的湿岩靴。弹窗必须写：「此关缺速，换上后速 +N，可过墙 / 仍差 N」。

### 3. 地点三层

8 个地名不动。每地加三层，仍是当前一个挂机点。

| 层 | 解锁 | 怪物 | 掉落 |
| --- | --- | --- | --- |
| 外围 | 进关即有 | 现有表 | 现有白/对应品质 |
| 深处 | 本关外围斩杀 ≥ 80 | 同种 +35% 攻防血 | 合阶材料、更高概率本阶装 |
| 头目 | 深处斩杀 ≥ 120，且短板过墙 | 1 只头目循环 | 套装件、功法残页、丹 |

历练页地点行改成：`雾鸦岗 · 深处` / `雾鸦岗 · 头目未至`。不新开页。8×3 = 24 个可挂位置，目录本身就要来回跑。

### 4. 同阶套装（只看身上）

每阶五件（剑盔衣鞋佩）共用一个 `set_id`。只算**当前穿戴**，不进永久账号。

```text
同套 3 件：有效伤害 ×1.06
同套 5 件：有效伤害 ×1.12，且受伤 ×0.92
```

换关若短板变了，5 件套可能要拆。这才能让人回头刷旧关凑齐，而不是永远穿最新一把剑。

### 5. 功法小成、丹药限时、材料温养

- **功法**：第一次参悟 = 入门（现状）。再交 2 本同名残页 = 小成（技能攻防血 ×1.4）。大成不做进这 5 小时。残页从垃圾变成第二次选择。
- **回气丹**：服 10 分钟，修为效率 ×1.15。突破墙前才值得吃。
- **养体丹**：服 10 分钟，防御 ×1.20。过断魂谷一类短板。
- **温养**：3 灵草 + 1 兽骨，对一件未穿装备做一次「温养」，永久 +一档速度（鞋）或 +一档防御（衣盔）。每件只能一次。不是重铸，不改品质。

服食和温养都在行囊弹窗里，功法页仍然只展示已学。

### 6. 见闻（轻图鉴）

塞进历练页底部，不进底栏。见过的怪物名、斩杀数、是否出过头目。用来回答「这关刷够没有」，并作为深处 / 头目解锁的可见进度。不做收集完成度奖励（那是下一圈）。

## 五小时时间轴（在线整理 + 挂机）

「试玩完毕」的终点：筑基后期已至，古碑台外围挂上，见过至少一件红装，合阶到过 +3，穿过一套 5 件，用过两种丹，黄/玄/地各小成或入门过一本，天书因境界看得到学不了。

| 墙钟 | 境界大约 | 历练 | 必须亲手做的事 |
| ---: | --- | --- | --- |
| 0–20 分 | 凡人 → 炼气初 | 杂木林外围 | 穿第一件、点开弹窗、合第一次、学吐纳 |
| 20–50 分 | 炼气中 | 野猪坡墙（缺攻） | 留下第二把刀合 +1，而不是穿散件 |
| 50–90 分 | 炼气后 | 青石涧（缺速） | 换鞋/佩，3 件凡套或第一件蓝 |
| 1.5–2.5 时 | 炼气圆满 → 筑基初 | 雾鸦深处、断魂外围 | 第一次吃养体丹过防墙；玄阶入门 |
| 2.5–3.5 时 | 筑基中 | 断魂头目、赤焰外围 | 紫装 3 件套；合 +2 |
| 3.5–4.5 时 | 筑基中后段 | 赤焰深处、沉渊外围 | 金装散件；试 5 件套与短板的取舍 |
| 4.5–5 时 | 筑基后 | 古碑台外围 | 见红、见天书、头目仍缺短板 —— 目录走完 |

金丹三阶仍留在表里，给第二次回来和 8 小时离线用，不计入「五小时试完」。

## 表要改的数字（原则，不是最终表）

- 野猪坡起，短板门槛单独抬，总战力墙只作辅。现在的 32 / 55 / 90 太矮。
- `loot_chance_scale` 维持 0.2 附近。合并靠「同名再掉」，不要把爆率拉回满包爆炸。
- 深处、头目的斩杀门槛按「这一关要挂 15–25 分钟」反推，用现有击杀耗时公式校。
- 前三阶修为时间不动（17 分钟）。五小时长度加在历练收集上，不把凡人再拉成半小时。

## 存档

本方案落地时 `schema_version` 升到 3。新增：装备 `merge_level`、`tempered`（是否温养过）、当前地点层、各地斩杀计数、功法等阶、丹药时效时间戳。v2 旧档：合阶 0、层为外围、斩杀 0、功法入门、无时效。随后功法运转在 `0.1.15` 升到 schema 4；长线架构计划目标为 schema 5。

## 落地状态（0.1.14）

六层都已进 0.1.14。表按短板墙抬过；前三阶修为时间没动。玩家用检查更新覆盖后，旧档合阶从 0、层从外围开始。

| 步 | 内容 | 玩家立刻感到的 |
| --- | --- | --- |
| A | 合并 + 短板墙 + 弹窗改写 | 行囊开始有选择，下一关会卡住 |
| B | 三层地点 + 见闻计数 | 同一地名也能刷很久 |
| C | 3/5 套装 | 回头刷旧关凑齐 |
| D | 功法小成 + 丹药服食 + 温养 | 分类不再空，残页和丹有用 |
| E | 按时间轴调表 | 真的坐满约 5 小时才到古碑台外围 |

A 就能验证「不是永远穿最大战力」。E 完成前不加新底栏、新货币、新经营；该约束已经随 `0.1.14` 完成。后续只按 `docs/design/long-term-progression.md` 的里程碑发布经营系统。

## 验收（五小时目录）

- 不看攻略，按提示能独立完成：穿、合、卸、换短板、进深处、服丹、小成、温养。
- 野猪坡之后至少有一次「战力够但短板不够」的失败。
- 同一把高战力武器在至少一关上不如低战力对短板件。
- 5 小时内能见到红装和天书，不能在 90 分钟内点进古碑台头目。
- 底栏仍是五页。旧档能进，合阶与层从零开始。

## 长线交接

- 本篇的装备合阶、短板墙、地点层、套装、丹药、温养和见闻在长线页面迁移后必须继续可达。
- 历练产出的药材、矿材、兽材和重复装备从 Day 7/30 起接入洞府供需，但 Day 1 不提前倾倒无用途材料。
- 五小时终点之后按 `docs/design/long-term-progression.md` 的 Day 7、30、90、180 目标继续，不通过追加第六底栏拉长目录。
