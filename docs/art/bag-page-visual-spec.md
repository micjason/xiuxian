# 行囊页视觉规格 2026-09-13

对照用户确认的整页稿（夜山立绘、圆环五槽、四列空格）。本文只定这一页的画法分工、风格和尺寸，不改玩法。装备、丹药、材料、功法图标仍用 `docs/art/chatgpt-image-prompts-bag.md` 第 3–4 节，不在本批重出。

基准画布：**1080×1920**。Godot 按竖屏锚点缩放，规格按这张稿写像素。

## 和现有界面的差别

| 稿面 | 仓库现状 | 本版怎么跟 |
| --- | --- | --- |
| 整页山水当底 | 渐变色块 + 深绿卡片 | 换背景图，去掉行囊页那张实心卡片 |
| 修士站在山石上 | 三列网格里一个圆章，文字写「凡人修士」 | 独立立绘叠在背景空石上 |
| 五槽是金边圆环 + 剪影 | 72px 方钮，空槽只写「头盔」等字 | 圆环用代码画，剪影出图标 |
| 底栏有图标 | 只有五个字 | 图标出图，字仍用 Label |
| 底栏是修炼/历练/行囊/功法/设置 | 现为修炼/历练/洞府/行囊/功法，设置在顶栏齿轮 | **底栏保持五页+洞府**，设置继续顶栏；稿里的设置图标改作出「顶栏齿轮」 |

## 风格

- 安静、克制、偏贵气。写实偏工笔夜山，不要花哨描边、霓虹、Q 版。
- 底：松墨夜青。字：象牙。强调：古金细线。弱字：青灰。
- 控件尽量透，让山水露出来；字的可读性靠上下压暗，不靠再盖一张大卡片。
- 标题用宋系（`MainTheme.title_font`：宋体 / Source Han Serif SC）。正文和按钮用黑体（`MainTheme.body_font`：苹方 / 思源黑体）。

## 布局（1080 宽）

从上到下，Y 为约值，实现时用锚点和最小高度，不要写死到每个控件。

| 带 | 高度 | 左右边距 | 内容 |
| --- | --- | --- | --- |
| 顶栏 | 56 | 36 | 境界左、战力右 |
| 修为胶囊 | 36 | 120 | 居中，「修为 0/360」+ 细金进度 |
| 装备板 | 720 | 36 | 立绘居中，五环绕槽 |
| 行囊标题 | 36 | 16 | 「行囊 0/100」，左右金饰 |
| 分类 | 40 | 16 | 五胶囊，间距 8 |
| 网格 | 余下，可滚 | 16 | 8 列正方形格，间距 6，容量 100，隐藏滚动条 |
| 底栏 | 210 + 安全区 | 0 | 贴屏幕底，只留 Home 条；图标 96 + 字 36 |

装备板内部：

- 立绘显示高约 **460**，脚落在画面中线略下的空石上。
- 圆环直径 **88**，金边 1.5px，剪影 40。
- 槽字在圆下 6px，宽不超过 88。
- 相对立绘中心：头盔 (0, −210)、武器 (−168, −36)、玉佩 (+168, −36)、衣服 (−88, +168)、鞋子 (+88, +168)。这是稿面比例，小屏先保圆环不重叠立绘。

## 元素分工

### 代码画（不出图）

- 全部文字和数字。
- 顶栏左右装饰菱形、修为胶囊外壳、进度条、行囊标题两侧细金饰。
- 五槽的圆底、金圈、按下态；已穿时金圈改品质色。
- 分类胶囊、八列正方格、滚动、品质描边。
- 底栏选中/未选中的字色和细金线。
- 上下压暗：顶 200px、底 360px 的黑青渐变，保证字能看清。
- 物品详情弹窗继续用现有卡片+按钮，本批不动。

空格不要出图。四列重复一张位图在小屏上会糊，也难换选中态。

## 叠法

```text
背景图（全屏，裁切保持山石在中下部）
  + 顶/底压暗（代码）
  + 立绘（脚对齐空石）
  + 五圆环 + 剪影或已穿物品图
  + 顶栏 / 修为 / 行囊标题 / 分类 / 网格
  + 底栏
```

背景和立绘必须分开。人画进背景就没法换装，也没法在小屏上单独缩放。

## 验收

- 空袋时，五个圆环里只有淡剪影，下面格子是空的。
- 已穿装备只出现在圆环里，不进下面网格。
- 「全部」胶囊是唯一实心金底。
- 底栏「行囊」图标和字是古金，其余弱。
- 1080 宽上左右边距看起来接近 36，圆环不压到立绘肩膀。
- 素材进包前按 `docs/art/asset-register.md` 登记来源和许可。
