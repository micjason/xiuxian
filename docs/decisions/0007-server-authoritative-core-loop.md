# ADR-0007：服务器权威的核心循环

- 状态：已接受
- 日期：2026-10-08
- 决策者：项目负责人
- 取代：ADR-0005 中「突破确定成功，不增加随机失败」

## 背景

手机里仍有一整套本地结算，服务器只算了修为和突破。项目负责人要求突破有概率，战力越高越容易成功，并带保底。内容必须由后台草稿发布成不可变快照，手机只展示。

## 决策

1. 突破改为有概率。成功率受战力影响，连续失败会提高下次成功率。公式见 `docs/roadmap/02-target-architecture.md` §2.5。
2. 客户端只展示。所有本地结算代码下线。旧手机本地存档不迁入账号。
3. 内容模型改为「一份草稿表 + 不可变发布快照」。概率统一用万分比。
4. 后台菜单分六组：内容配置、发布、数值工具、玩家、运营、测试工具。GM 工具只在测试环境开启。
5. 洞府、门派、灵兽、远行、飞升暂停，第一版不上线。

## 备选方案

- 继续确定突破：无法形成「打关卡、换装备、提高战力、再突破」的循环。
- 把旧存档迁进账号：本地规则和服务器规则已经分叉，迁档会算错进度。

## 后果

### 正面

- 手机和服务器只保留一套规则。
- 后台改的数值发布后，手机读到的是同一份快照。

### 负面

- 已安装的 `0.6.x` 客户端与新表结构不兼容，完成客户端改造前不得把新后端切到正式服。
