# 技能特效色板与造型约定（对齐动画 · 2026-10-29）

配合：`q_skill_vfx_style_board.png` · 动画约束（挂点/时长/Godot）· Q 战斗页 1080×2340

## 总原则（Q 竖屏挂机）
- **贴合**现有 Q 战斗页：可可描边感 `#6B4A3A` 世界、面板奶白、主 CTA 暖橙；特效比风格板**更干净**，少碎屑/少裂纹。
- 可见主体约 **400～700 px**；**勿挡**血条、名字、飘字区。
- 线条：**中等偏粗**（弧光/雷枝清晰可读），不做写实细丝。
- 粒子：**中低密度**（手机连放不糊）；单次 0.5～1.2s 内收干净。
- 每套导出 **主色 / 辅色** 两档，方便批量换色。

## 四套色板

| 套 | 主色 | 辅色 | 造型 | 挂点 |
|----|------|------|------|------|
| 斩击/刀光 | `#F5FBFF` 银白 | `#A8E8E0` 淡青 | 1～2 道水平弧，短拖尾；少火花 | 目标身前 |
| 雷 | `#E8D6FF` 浅紫白芯 | `#7B4DFF` 紫 | 1 主落雷 + 1～2 枝叉，**别太密**；地面一闪小圆 | 天顶→脚底 |
| 火 | `#FF9F43` 暖橙 | `#FF5A5F` 红 | 中心短爆 + 向上火星；地面焦痕**小** | 目标中心 |
| 法阵·治疗 | `#5EE1C5` 青 | `#FFE27A` 浅金描边 | 脚底圆环 + 柔和上升粒子，不抢戏 | 己方脚底 |
| 法阵·攻击（扩） | `#FFD45C` 金 | `#5AAEFF` 青蓝 | 同心符文环 + 短柱光，比治疗更「硬」 | 目标脚底 |

## 节奏
- 斩击 / 雷 / 火：**0.5～1.0 s**
- 治疗法阵：**0.8～1.2 s**
- 全自动连放：淡出要干净，避免叠层过曝。
