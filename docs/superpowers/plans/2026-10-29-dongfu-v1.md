# 洞府 v1（药园 / 炼丹 / 总览）Implementation Plan

> **For agentic workers:** Use task-by-task implementation. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 洞府底栏总览 + 药园种植领取 + 炼丹队列领取可玩闭环；强化入口只 emit 信号由独立开发超级大师接线。

**Architecture:** 服务器权威：`player_dongfu_plots` / `player_dongfu_alchemy` 存种植与炼丹队列；读 state / 写接口前按 `now` 结算 `ready`。内容配置进 `content_globals.dongfu` + 种子/配方表（或 jsonb）。客户端重写 `CavePage` 为三卡总览 + 药园/炼丹子页。强化第三卡只 `enhance_entry_requested.emit()`。

**Tech Stack:** Node + Fastify + Drizzle/Postgres、Vue3 后台、Godot4 客户端。Worktree: `/workspace/xiuxian-ui-dongfu`，分支 `proto/dongfu-v1` ← `origin/dev2`。

**设计依据:** `docs/superpowers/specs/2026-10-29-dongfu-v1-design.md`

- 后端：`cd backend && npm test` / `npm run typecheck`

## 接口契约（已与超级大师确认）

`GET /me/state` 增加 `dongfu`：
```json
{
  "plotCount": 4,
  "alchemyQueueLength": 2,
  "plots": [{ "slot": 0, "seedSlug": null, "herbSlug": null, "plantedAt": null, "matureAt": null, "status": "empty|growing|ready" }],
  "alchemy": [{ "id": "uuid", "recipeSlug": "...", "startedAt": "...", "readyAt": "...", "status": "crafting|ready", "outputItemSlug": "...", "outputQty": 1 }],
  "claimable": { "plots": 0, "alchemy": 0 }
}
```

- `POST /me/dongfu/garden/plant` `{ slot, seedSlug }`
- `POST /me/dongfu/garden/claim` `{ slot? }` 省略=全部 ready
- `POST /me/dongfu/alchemy/start` `{ recipeSlug }`
- `POST /me/dongfu/alchemy/claim` `{ jobId? }` 省略=全部 ready

itemSlug：`seed_lingcao`→`herb_lingcao`，`seed_qingxin`→`herb_qingxin`；`pill_cultivate` / `pill_atk_temp` / `pill_def_temp`  
临时丹 effect：`{ buffStat, buffBp, durationSeconds }`（战斗结算归开发二号）

客户端：`signal enhance_entry_requested`；PlayScreen 接线归超级大师。
