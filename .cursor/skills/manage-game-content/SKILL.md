# 管理游戏内容

## 原则

- 原始工程和候选素材放 `content-source/`；筛选、优化后的运行时副本才进入 `game/assets/`。
- 未确认正式美术风格前使用清晰、可替换且体积小的占位资源。
- AI 生成不等于无版权风险；所有素材都必须能追溯来源、模型/网站、许可证和生成提示。

## 流程

1. 明确用途、目标尺寸、透明度、循环方式、时长、平台和替换条件。
2. 获取或生成素材前检查商用许可、署名要求、再分发限制和相似性风险。
3. 在 `docs/art/asset-register.md` 登记唯一 ID、来源、许可证、作者、获取日期和用途。
4. 保留原始文件；导出移动端适用格式、分辨率、采样率和压缩版本。
5. 以英文 `snake_case` 命名，按 UI、角色、环境、物品、特效、音乐、音效等归档。
6. 导入 Godot 后检查纹理过滤、压缩、循环、字体回退和实际设备内存。
7. 删除或替换运行时素材前搜索引用；原始素材除非用户批准不得删除。

## 质量检查

- 不含竞品商标、角色、界面复制或明显水印。
- 手机屏幕上可读，边缘、透明通道、循环点和响度正常。
- 文件大小与内存成本符合当前预算；重复资源得到复用。
- Git LFS、许可证登记和 Godot 引用均正确。

## 输出

说明新增/替换素材、来源许可、运行时预算、导入设置、引用位置和仍需人工审美确认的内容。
