# 后台战斗动画（2026-11-18）

只做后台。游戏端还没读这份动画，Godot 没改。

## 决定

- 玩家当前动画只有一份。保存立刻写入，没有草稿、没有发布按钮。
- 上传 8 秒以内的视频（每秒 12 帧）或已经切好的 PNG。品红底抠掉，本身透明的 PNG 不重抠。
- 待机帧决定缩放和脚底，之后每一帧用同一套脚底，跳跃不会被按回地面。
- 素材预览和入战预览用同一套帧序号、循环和冲刺。入战预览只演待机、普攻、施法、技能、受击、胜利。技能命中时刻默认 1.21 秒，先记在动画包上。
- 缺待机、普攻、施法、技能、受击、倒地、胜利时不能保存，并写出缺哪个。剑气和命中可以先空着。
