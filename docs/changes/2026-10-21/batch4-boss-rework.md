## 规则（一关一个首领、一套规则）
- 精英 / 章末首领两套规则合成一套（配置概览 ·「首领规则」），每关可单独覆盖（关卡抽屉 · 首领规则，改过的显示「已自定义」）。
- `tier`（elite/chief）只留作外观字段，规则不再区分；客户端一律按「首领」样式显示。
- **默认值（待确认）**：属性自动＝普通怪 × 倍率（气血 5 / 攻击 1.3 / 防御 1.2）；允许重打、重复奖励开；
  首通装备品质 白0/绿70/蓝25/紫5/橙0，重复 白0/绿50/蓝35/紫13/橙2；自动挑战开（战力 ≥ 推荐 100%，输了 60 秒后再试）；
  解锁＝击败上一关首领 + 境界；挂机刷首领开，每 1000 波一只，一次结算最多 20 只；每日首领挑战总次数 5。
- **每日总次数**（全局，只能在配置概览改）：没击败过的首领第一次挑战不算；日界用 `dayStartHour`。
  挑战本身不受次数限制：次数用完照样能打，只是没有奖励。
- **挂机刷首领**：每关独立计数（`player_stage_progress.idle_waves`，离线结算也算），满 N 波刷一只直接打，大招自动；
  奖励走 `grantEquipment(boss_repeat)`，requestId 幂等。
  「挂机首领算每日次数」开关**默认关**（成鹏定）：关着时不扣次数、次数用完照样发奖励；打开后次数用完照打、不发奖励。
- **大招全自动**：蓄满后 `ultAutoCastWindowSeconds`（默认 2 秒）自动放，老客户端传的点击时间一律忽略。
- **行囊已满**：继续调 `grantEquipment`，兼容读 `skipped: 'bag_full'`；手动 / 自动 / 挂机首领结果都带 `bagFull` 和被跳过的物品，客户端提示「行囊已满，装备未拾取」。
