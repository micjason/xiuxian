## 各对象：五套系统怎么排、怎么咬

每条只写原文能支撑的。缺的写「未见」。

### 1. Melvor Idle（A1–A6）

最接近「纯文字挂机战斗 + 银行 + 穿戴 + 技能栏 + 设置」的单机样本。

- **页面排布**：左栏一列按钮：战斗技能、生活技能、银行、商店、设置。主区换页。战斗页上部三个页签（普通区 / 猎杀区 / 地下城），下面是装备栏和战斗数值。银行是独立整页，点物品才出右侧操作板。设置在左栏底部，按分类堆叠（A1、A2、A5）。
- **战斗**：选地点 → 看该点怪物血量/等级/攻击类型/掉落表 → 点 Fight。敌人自动互砍，直到逃跑、死亡或通关地下城。掉落进战利品容器，要手动「全拾取」或靠后期装备自动拾取；超过约 100 堆会挤掉最旧的（A1、A2）。
- **战斗记录**：没有逐回合文字战报（A6）。另有完成日志：遇到次数、击杀、被杀、命中、未命中、伤害进出。掉落明细不在这份累计里（A6）。
- **背包**：容量有限，商店买格，价随次数涨。分页、搜索、锁定防卖、新品高亮（A3）。满包时可在设置里选择「继续干活但不进包」（A5）。
- **装备**：从银行点「装备到某套」。有多套方案。槽位一览可从装备栏图标进（A4）。穿上才改战斗数值。
- **技能**：左栏每个技能自己一页。战斗技能（攻/力/防/血/射/法/祈/猎）和采集技能并列，不是战斗页里的一棵树（A1）。
- **设置**：战斗（含离线战斗开关，默认关）、通知、界面、性能（可关伤害跳字和进度条）、存档导出/删除（A5）。
- **时长从哪来**：地点梯子 + 技能等级墙 + 套装门槛 + 银行格不够要管理。不是「一种怪物无限刷到腻」。怪物是有限目录，分区投放（A2）。
- **未见**：竖屏五底栏；修仙境界穿衣门槛（它用技能等级门槛）。

### 2. 想不想修真（A7–A9）

国内放置修仙、竖屏底栏的主样本。

- **页面排布**：五个主界面——修炼、灵根、功法、洞府、仙缘。左上头像进储物袋和装备栏。储物袋下还有属性 / 炼丹 / 炼器（学对应书后开）。右上奇珍、坊市（A7、A9）。
- **战斗**：仙缘里打怪/探索；出窍期后可学「元婴出窍」类自动挂机。挂机结束收益进背包；背包满且没买补遗时，装备类收益会丢，要靠地摊清格（A8）。
- **战斗记录**：这几页没写逐回合文字战报。只写「挂完把收益返还背包」。
- **背包**：储物袋，格数可扩。地摊卖未上锁物清包（A9）。挂机收益和背包容量绑死（A8）。
- **装备**：头像页约 12 个槽。前期装备来自仙缘打怪；学会炼器后可用图纸把原始防具重铸（A7–A9）。攻略把前期堆防写成过图条件（A9）。
- **技能/功法**：独立「功法」页。心法/决/身法/遁术/真经/绝学等分类。入门派后用技能点领悟；灵根加成对应系（A7、A8）。
- **设置**：这几页几乎只写玩法按钮，没有独立「系统设置」页的细目。
- **时长从哪来**：五条入口同时在，修炼涨境界，仙缘产装，功法产属性，洞府产资源，背包满了要处理。过图条件是属性墙，不是再点一次突破。
- **未见**：单机本地结算细节；官方设置分类。

### 3. 一念逍遥（A10–A12）

商业修仙网游。用来看「城镇枢纽 + 角色页 + 装配方案」，不是单机模板。

- **页面排布**：城镇是枢纽。头顶看法修/体修进度和两种货币。头像进声音和世界播报设置。城镇里天机阁、论剑、坊市、信箱、排行、NPC 各开一页（A10）。角色页管装备、古宝、功法/神通。
- **战斗**：出门冒险/秘境/论剑。官方后来把战斗装配从 2 套扩到 4 套，可在装配页直接换装，可手动排施放顺序（A11）。有飘字优化（A12），不是纯文字战报。
- **战斗记录**：论剑有「战绩」看打了谁、被谁打（A10）。未见野外挂机的逐条文字战报。
- **背包**：有溢出走信箱（A10）。炼器宗师可用贡献扩背包（A10）。官方改过背包红点，可在道具展示里关部分红点（A12）。
- **装备**：装配页换装；多套战斗方案按玩法解锁（A11）。坊市定时刷材料/丹药/功法/装备（A10）。
- **技能/神通**：角色页装配，有数量上限（玩家向视频写「一次带有限个神通」——本篇不把视频当硬证据）。官方修过神通装配失败和红点（A12）。
- **设置**：头像里声音和播报（A10）。另有玩法内设置（批量探索等），会跟设备走（A12）。
- **时长从哪来**：服务器真挂机 + 日次数 + 城镇多入口 + 装配方案。这是另一品类。
- **未见**：单机公式；纯文字战斗日志。

### 4. IdleOn（A13–A15）

挂机打怪产掉落，天赋改战力，背包格限制 AFK 时长。

- **页面排布**：角色在地图上。菜单叠层：I 背包、T 天赋、Q 攻击栏、Esc 总菜单、C 图鉴。AFK 预览在菜单的 AFK Info（A13、A14）。
- **战斗**：开自动攻击后可关游戏，回来领经验/钱/物品。AFK 是按数值模拟，不是逐帧重放。AFK Info 显示每小时击杀、经验、金钱、命中、生存率、免伤所需防御（A13、A14）。地上掉落会过期；背包不够就捡不完（A13）。
- **战斗记录**：未见逐回合文字 log。用 AFK 预览和回来结算代替「刚才发生了什么」。
- **背包**：角色背包 + 仓库。前期格很少；任务/商店/掉落扩格。堆叠有上限。格不够会缩短有效 AFK（A13）。
- **装备**：有等级门槛。前期装多从首领/打造来。武器尽量用当前能做的最高阶（A13）。
- **技能/天赋**：升级得点。有战斗预设和采集预设。主动技拖到热键栏后才会自动放，**且影响离线收益**（A13、A15）。
- **设置**：新手页写自动攻击要在设置里打开（A15 引用的新手流程）。未见完整设置分类表（本篇能打开的页不够）。
- **时长从哪来**：地图墙（命中/生存不够就推不动）+ 背包墙 + 多角色 + 天赋加点。怪物按地图投放，不是无限随机种。
- **未见**：纯文字战报；竖屏修仙底栏。

### 5. NGU Idle（A16–A18）

和用户描述最贴的「挂机战斗 + 底部战报 + 掉落进包 + 穿装推进度」。

- **页面排布**：顶栏切系统。冒险页从上到下：区名、技能三行、左右切区、中间对战（己方数值 | 敌人像 | 敌方数值）、**底部战斗日志**（A16）。背包是另一页：穿戴、合并、强化、方案、物品图鉴（A17）。设置是左下齿轮，分页（A17、A18）。
- **战斗**：击败第 4 个 Boss 才开冒险和背包（A17）。两种打法：Idle Attack（每秒一击，回血加成，关掉其他技能）和手动放技能。区是有限列表，箭头/下拉切换；打不过就停在当前区（A16）。另有无限层塔：相邻层约 1.05 倍，用来在「区与区之间」继续刷（A16）。
- **战斗记录**：底部显示最近战斗事件。部分首领战要读这条 log 才能打（A16）。这是五款里唯一写明「战斗页自带文字战报」的。
- **背包**：冒险掉落进包。可锁定防扔、合并同名装、强化、过滤垃圾掉落。容量有限，可把格改成自动合并格（A17、A18）。
- **装备**：冒险掉落是主进度来源。同件合并升级，凑齐一套有永久加成。穿上的 Power/Toughness 同时喂战斗和主线数值（A16、A17）。
- **技能**：战斗页上三行技能。前两行随基础训练解锁，第三行另有条件（A16）。Idle 模式不用它们。
- **设置**：数字格式、主题、提示、战利品过滤、自动击杀首领、背包快捷键简化、在线自动击杀开关（离线仍会自动尝试）（A18）。
- **时长从哪来**：区墙 + 套装收集 + 合并到满 + 首领冷却 + 塔层。指南写明：只堆数字会卡死，换一套装才能往前（A16）。
- **未见**：修仙境界；移动端底栏。

### 对照样本：一念修仙（A21）

商店页自称极简，对抗「操作党 / 数值繁琐」。公开系统是吐纳、离线、功法、洞府、灵根、破境，**未见战斗/装备**。说明「五套系统」不是修仙放置的必选项；加它们等于换产品密度。

## 跨产品重复出现的结构

1. **战斗是选点挂机，不是无限随机怪物生成。** 地点有限，每点有限怪物目录（A2、A13、A16）。「无数种」在这些产品里体现为目录随版本加长，不是一场里随机无穷种。
2. **掉落必须有容器。** 战利品栏 / 背包 / 信箱 / 地上过期，四选一或组合（A2、A8、A10、A13）。满了会丢或停，这本身是一条循环。
3. **装备不在战斗页生成，而从容器穿上。** 银行/储物袋/背包 → 槽位（A3、A4、A7、A17）。
4. **穿戴有门槛。** 技能等级（A4）、角色等级（A13）、境界/玩法解锁（A8、A11）。用户说的「修为升级才能穿更高阶」属于这类墙，五款都有墙，墙的尺子不同。
5. **技能改的是战力或效率，用来过下一道墙。** 功法加攻防（A8）、天赋加伤害/命中且影响 AFK（A15）、战斗技能行（A16）、Melvor 的战斗技能等级（A1）。
6. **更高场景按战力/进度解锁，不会一次铺开。** Melvor 分区、IdleOn 地图、NGU 区与首领、想不想修真出窍后才自动挂机（A2、A13、A16、A8）。
7. **设置是独立页，不塞进战斗。** 至少含：通知/音效、自动战斗或离线战斗、战利品处理、存档（A5、A10、A18）。
8. **时长来自墙，不是来自按钮数量。** 赚→花→加速→墙（A19）。装备/技能是「花」，下一区是「墙」。只加页面不加墙，几分钟仍然结束（A19、A20）。
9. **多套装配是中后期减摩擦，不是开局内容。** Melvor 多套、逍遥 2→4 套、IdleOn 战斗/采集双预设（A4、A11、A15）。
10. **逐回合文字战报不是标配。** 五款里写明有的是 NGU 底部 log（A16）。其余用结算摘要、累计图鉴或录像。用户要的「面板显示战斗记录和得到了什么」更接近 **NGU 战报 + Melvor/IdleOn 结算掉落** 的组合，而不是五款都这么做。

## 对照本项目（只写仓库事实）

- 现在只有一条循环：时间产修为 → 突破 → 效率变高 → 离线补一次，顶 8 小时。见 `mvp-scope.md`、`cultivation-foundation.md`。
- 主界面 `game/scenes/main.tscn` 是单页：境界、修为、效率、突破、简记、更新。没有底栏，没有第二页。
- 境界表 8 阶，前三阶在线合计设计不超过约 90 秒。到筑基后期 `next_id` 为空。
- `mvp-scope.md` 仍写着首期不做战斗、装备等第二核心循环。开这五套 = 改产品边界，要负责人确认并补 ADR。
- 没有背包、物品、装备槽、技能点、战斗地点、战报、设置页（更新通道不算游戏内设置）。

## 页面该怎么排（只综合能核对的移动/放置结构）

竖屏国内修仙（A7）用**底栏分系统**；桌面放置（A1、A16）用**侧栏/顶栏**。本项目是 Android 竖屏，和 A7 同形态，不要抄 Melvor 左栏。

五款里反复出现的分区，映射到本项目现有单页时，结构是：

```text
顶栏：境界 / 修为 / 货币（现在已有境界和修为）
主区：当前页内容（一次只显示一个系统）
底栏：修炼 | 历练 | 行囊 | 功法 | 设置
```

各页在竞品里实际装什么（不抄文案）：

| 页 | 竞品对应 | 页内分区 |
|----|----------|----------|
| 修炼 | 想不想修真「修炼」；我们现在的主屏 | 效率、突破、离线回执、简记。不放战斗。 |
| 历练 | Melvor 战斗页；NGU 冒险页；想不想修真「仙缘」 | 上：可选地点（未解锁灰显）。中：当前敌人名、双方摘要数值、进行中/挂机中。下：**滚动文字战报**（NGU）+ **本场/本次结算掉落**（Melvor 战利品栏 / IdleOn 回来领奖）。 |
| 行囊 | Melvor 银行；想不想修真储物袋；NGU/IdleOn 背包 | 格网 + 点选后的操作（穿、锁、弃）。装备槽可做行囊顶栏或头像页，不要和战斗日志抢同一屏（A3、A7）。 |
| 功法 | 想不想修真功法页；IdleOn 天赋；Melvor 则是左栏技能 | 可学列表、已学、消耗、对战斗数值的可见加成。用境界/技能点解锁，不要开局铺满（A8、A15）。 |
| 设置 | Melvor/NGU 独立设置；逍遥头像设置 | 音效、战报开关、数字格式、自动拾取/满包策略、存档导出。不放养成（A5、A18）。 |

装备不必第五个底栏：五款都把「穿」放在容器或角色页，不跟战斗抢入口（A4、A7、A17）。

## 五套系统怎么咬成一条，而不是五张空页

竞品里能核对的依赖顺序（A16、A17、A2、A3、A8、A13）：

```text
选地点挂机
  → 文字结算：谁死了、掉了什么
  → 进行囊（满则丢或停）
  → 穿上（境界/等级够才穿）
  → 战斗数值变
  → 功法再改同一组数值
  → 下一地点的墙（打不过就停在当前点继续刷）
  → 墙被推开，地点目录变长
```

这仍是 A19 的赚→花→加速→墙。修为突破继续做「时间轴」；历练做「战力轴」。两轴要互相锁：

- 境界锁：更高阶装备/功法/地点（用户已提出，A8/A13 也有同类锁）。
- 战力锁：地点打不过就回去刷，不让一次点完（A16）。
- 容量锁：包满是日常操作，不是惩罚彩蛋（A3、A8、A13）。

「几分钟结束」的直接原因在本仓库是：只有 8 阶、前 3 阶约 90 秒、没有「花」也没有墙。五套系统若做成「能点就点完」，时长不会变。时长来自**地点目录长度 × 过墙时间 × 收集/合并/学习**，不是来自按钮个数（A16、A19）。

怪物数量：五款都是**有限图鉴 + 分区投放**。要做「很多种」，按区加目录，并做图鉴累计（Melvor 完成日志 / NGU Bestiary，A6、A16）。不要做无目录的无限随机种——打开的页里没有这种主循环。

## 可借鉴 / 可优化 / 可融合 / 不能做

每条带来源。抄名称或数值的已删。

### 可借鉴

- **历练页 = 地点 + 当前战 + 底部文字 log + 掉落条**（A16 + A2）。这是用户要的面板，五款里只有 NGU 写明有文字 log，掉落条用 Melvor/IdleOn 的结算结构补。
- **底栏分系统，头像或行囊顶栏管穿戴**（A7、A3）。适合竖屏。
- **地点墙：打不过就停，继续刷当前点**（A16、A13、A2）。
- **背包有限 + 满包策略写进设置**（A3、A5、A8、A13）。
- **技能改同一组战斗数，用来开门**（A8、A15、A16）。
- **设置独立：音效、离线/自动战斗、战利品、存档**（A5、A18）。
- **图鉴累计击杀/掉落，不靠无限新种制造时长**（A6、A16）。

### 可优化（竞品痛点或我们已落后的点）

- **开局过短**：我们前三阶约 90 秒是演示节奏。A19 写移动放置第一圈墙常见在数小时。加战斗后，第一道地点墙应出现在「突破还没把表点完」之前，否则两套都会一起空。
- **想不想修真背包满丢装备**（A8）：结构可学「满包要处理」，不要学「没看说明就丢稀有」。Melvor 是挤掉最旧战利品或设置里忽略进包（A2、A5），更可预期。
- **Melvor 默认关闭离线战斗**（A5）：我们若做挂机战斗，离线必须写清上限（已有 8 小时修为顶），避免和修为离线两套账对不齐。
- **逍遥式城镇 NPC 堆入口**（A10）：竖屏单机会炸。底栏 4～5 个就到顶。

### 可融合（两家以上有，且能接在「挂机→突破」上）

1. **修为继续涨，挂机时同时打当前已选地点**（A2 离线战斗、A13 AFK、A8 出窍挂机）。回来一次结算：修为 + 战报摘要 + 掉落。
2. **境界锁装备和地点，战力锁下一地点**（A8、A13、A16）。两把尺子，缺一不可。
3. **行囊是掉落的唯一家，装备槽是行囊的子集**（A3、A7、A17）。
4. **功法/技能只改战斗数和效率，不新开经营**（A8、A15）。
5. **设置先做小集：音量、战报开闭、满包策略、存档导出**（A5、A18）。养成不进设置。

### 不能做

- 复制任何一款的地点名、怪物名、功法名、装备名、数值、美术。
- 服务器真挂机、论剑、宗门、信箱跨设备（A10、A12 + `mvp-scope.md`）。
- 一次做完五套的最终体量（Melvor 技能树、逍遥装配 4 套、IdleOn 多角色）。那是多年内容，不是一个版本。
- 开场飞升重置（A19、A20：重置在墙之后）。
- 「无数种怪物」做成无目录随机生成——打开的页没有这种主循环；有的是有限目录 + 塔/层数（A16 的无限层是同一公式加厚，不是新物种）。
- 视觉自动战斗录像当第一版（逍遥飘字、AFK Arena 回放）。用户要的是文字。
- 不经确认就把 `mvp-scope.md` 的「首期不做战斗/装备」直接作废。本篇是调研，不是开工许可。

## 若确认要做：证据支持的最小切片（仍不是开工）

只做能形成上面那条咬合、且能在一版里测完的：

1. 底栏两页：修炼（现有）+ 历练（1 个已解锁地点、3～5 种目录怪物、底部文字 log、掉落进有限行囊）。
2. 行囊：有限格、穿 1～2 个槽、境界不够不能穿。
3. 功法：1 个可学项，加可见战斗数，用来过第 2 个地点。
4. 设置：音量 + 战报开闭 + 存档导出。
5. 离线：继续用统一时间入口，一次结算修为和战斗摘要，共用现有 8 小时顶。

明确留到后面：多套装配、炼器、无限层塔、图鉴完成度、商店买格、日次数。这些在竞品里都是中后期减摩擦或第二圈（A4、A11、A16）。

## 证据不足

- 没有我们自己的对局录像：玩家是在炼气后期觉得没了，还是筑基后期触顶。
- 未合法试玩想不想修真 / 一念逍遥并记录「前 20 分钟出现过哪些按钮」。
- IdleOn 完整设置分类、想不想修真是否有逐条战报：打开的页不够。
- 「挂机战斗离线」和「修为离线」两套账如何共用一个 `last_settled_unix`：竞品有的分开关（A5），有的统一 AFK（A13），本项目还没定。
- 怪物目录要多长才撑过「几分钟」：没有我们的留存数据，不能从竞品页读出我们的分钟数。

要补证据：真机或官方试玩 2 款竖屏修仙，只记前 20 分钟按钮和第一道墙出现时间；不要靠回忆补。
