# 后台体验 3 点（2026-10-21，Chengpeng 经负责人）

只改后台网页，客户端不动、不发 APK。

## 1. 「?」提示图标 → 「!」
- 全后台的字段提示都走 `admin/src/components/HelpTip.vue`：图标从「?」改成「!」（表示这里有提示）。
- 悬浮时鼠标保持普通箭头（`cursor: default`），不再是问号 / help 光标；悬浮 200ms 照常弹出提示，点击可固定。
- 全局搜过：没有其他 `cursor: help` 或问号图标（GearView 顶部的「ⓘ」是说明条，不是提示图标，没动）。

## 2. 配置概览「编辑」直达关卡抽屉 + 各页签数据自动同步
- 配置概览「已自定义的关卡」表里的「编辑」：跳到「关卡与首领」页签并直接打开那一关的右侧编辑抽屉（`/config/stages?open=<关卡id>`，打开后自动去掉 query）。
- `ConfigListPage` 的 `?open=` 只认自己页面的路径（页面被 keep-alive 缓存，避免别的页签把 query 抢先清掉）。
- 通用的数据版本号 `admin/src/composables/dataVersion.ts`：`api()` 里任何非 GET 且成功的请求都会 +1（试打、公式预览、登录不算）；安装包上传也会 +1。
- 被缓存的页签切回来时（`onActivated`），如果版本号变了就自动重新读取；本页有未保存改动时不重读，免得冲掉正在改的内容。
- 已接入：配置概览（含首领规则使用情况）、关卡、章节、装备、强化、功法、境界 / 物品 / 建筑 / 公告 / 弹窗（`useList`）、战斗公式 / 模拟、运营概览、玩家、发布中心 / 版本 / 安装包、操作日志 / 补发记录。

## 3. 切页签保留滚动位置
- 内容区是 `el-main` 自己滚，keep-alive 不会保留滚动。现在 `AdminLayout` 在离开页签前记下 scrollTop，切回来时滚回原位（数据还在重读、高度不够时最多重试约 1 秒）。所有页签通用；新开的页签从顶部开始。
