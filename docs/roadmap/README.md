## 一句话结论

项目的方向（服务器权威、草稿/发布、操作留痕）是对的，但现在是“两套游戏叠在一起”：手机里有一整套本地单机玩法（约 1.2 万行 GDScript），服务器只做了修为和突破，而后台编辑的内容和手机读取的内容格式不一致，很多后台修改实际到不了手机。后端的关键写操作也没有真正放进数据库事务，接口走明文 HTTP。

后续路线是：**先加固后端地基 → 重做内容配置（后台）→ 在服务器上实现完整核心循环 → 把手机端改成纯展示 → 再做挂机、GM 工具和上线准备。**

## 和现有文档的关系

- 本组文档与 ADR-0005 有一处冲突：ADR-0005 规定“突破确定成功”，项目负责人现在的需求是“突破有概率，战力越高成功率越高”。以项目负责人的最新需求为准，任务 `P0-2` 会新增 ADR-0007 正式取代该条。
- 其他 ADR、设计文档继续有效，但涉及“手机本地结算”的部分全部作废，以 ADR-0006 和本组文档为准。
- `docs/superpowers/` 下的旧计划只作历史参考，不再执行。
