# 验证 Godot 项目

## 固定入口

- Godot：`/Volumes/kaixia/GodotDev/bin/godot`
- 工程：`/Volumes/kaixia/projects/xiuxian/game`
- 测试框架：与 Godot 4.7.x 锁定兼容的 GUT 9.7.x

若 `game/project.godot` 尚不存在，应报告“工程未创建，跳过运行时验证”，不得伪造通过结果。

## 验证顺序

1. 检查外接盘、Godot 可执行文件、版本、项目文件和 Git 工作区。
2. 运行无头编辑器导入并退出，捕获解析、资源引用和导入错误。
3. 对改动涉及的纯逻辑运行目标 GUT 测试。
4. 再运行完整单元测试；场景或装配变更补充相关场景测试。
5. 必要时进行限时最小启动，确认主场景能进入且无启动错误。
6. 保存测试结果摘要；生成报告只能写入被忽略的 `reports/`。

## 失败处理

- 保留首个根因和完整可执行命令，不用后续连锁错误掩盖它。
- 修复后从失败层级重新执行，再运行受影响的上层验证。
- 不通过关闭检查、删除测试或降低断言来“修复”失败。
- Godot 崩溃或挂起时记录退出码、日志位置和最小复现。

## 输出

逐项报告“通过、失败、跳过”及原因，列出命令、退出码、失败测试和未覆盖风险。只陈述实际执行过的验证。
