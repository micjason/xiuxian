## 后台走查：点了什么、发现什么

走查范围（每项都点到、看了结果）：

- 登录（错误密码被拒）、概览。
- 境界：打开编辑、把炼气三层突破消耗 1800→1900 保存→刷新确认→改回；新建境界空表单校验（请填写名称 / 大境界）；删除确认框能取消；复制。
- 物品：搜索、打开编辑和预算面板、新建空表单校验。
- 技能：打开编辑。关卡：打开黑风岭·三，首领编辑器；建一个"按配置算"的人偶后用它试打首领（输，第 13.5 秒被打死，给出每下伤害和用时）。
- 装备强化：改"每级经验增长倍数"保存到草稿→刷新仍是新值→改回；输入框把非法值夹到最小值（1.00），不会显示红字但也存不进非法值。
- 战斗公式与参数：负数被拒（"挑战冷却不能小于 0 秒"）；背包容量 20→22 保存→刷新→改回；试炼模拟新建人偶。
- 发布中心：体检→改动清单→填写说明；说明留空点发布被拦（"请填写发布说明"）；填写后二次确认→发布 v1；改背包容量再发布 v2，对比 v1/v2 只显示"行囊容量 20 → 21"；再发布 v3 改回。
- 版本历史、客户端安装包（空表单校验）、公告（新建空校验 / 新建 / 停用 / 搜索无结果）、弹窗（优先级填 −3 被拒"优先级不能小于 1"）、玩家（搜索、详情、操作日志、清空进度输错账号被拒且玩家数据不变）、操作日志查询与重置、设置（深色模式）、全局搜索 Ctrl+K。

发现并已修：

1. **体检误报**：无首领的历练关卡、只靠首通 / 重复奖励的首领被判成错误，发布按钮被挡。`admin/src/composables/healthCheck.ts`、`BossEditor.vue` 文案。
2. **境界保存被卡死**："突破前要先通关"这类选项在运行时才加载的下拉，校验时拿到空选项列表，把任何合法值都判成"选项不存在"。`admin/src/schema/validate.ts` 现在用页面传入的选项，选项没加载就不校验。
3. **玩家详情战力来源**：所有物品（含技能书、突破石）都标成"武器"，合计显示 `119.06000000000002`。后端分组改为"物品"，显示时取整到 2 位。
4. **登录页控制台 404**：浏览器请求 `/favicon.ico`。加了内联图标。

没有修、也没法在这里修的：

- 关卡页"试打"在没有人偶时只弹"还没有人偶，去新建"，这是预期行为。
- 客户端安装包上传没有真的传 apk 走完（没有手机可装，只测了校验）。

## 客户端与设计稿的已知差异（诚实清单）

- 英雄 / 首领是剪影占位（没有人物 / 首领切图）；沙漏、顶栏背景、`tab_cave`、`ult_btn` 是占位图。
- "自动战斗"只是状态显示（服务器大招一直自动释放）；x1 / x2 倍速只影响回放。
- 突破页要滚动才能看到"突破后"一行；主页的修炼行和顶栏重复，击杀 / 掉落反馈同时以飘字和波次卡显示。
- 背包的物品详情条换成弹窗；功法页没有"获得："行；洞府数据是静态的。
- 心跳间隔取 `clamp(onlineGapSeconds − 3, 1, 15)` = 12 秒，不是字面的 15 秒（服务器的在线间隙是 15 秒，间隔必须小于它）。
- `panel_popup_scroll` 不是终稿；美术切图只在尺寸与切图清单一致时才拷进来，没有覆盖 LFS 资源（本机没装 git-lfs）。
