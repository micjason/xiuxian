# MVP 产品边界

## 产品定位

- Android 优先的竖屏 2D 单机放置修仙游戏。
- 先验证成长反馈和留存循环，不追求正式美术。
- 参考同类产品的交互密度，但不复制其名称、文本、数值、美术或代码。

## 可玩闭环

修为轴：

1. 玩家随时间获得修为。
2. 界面展示当前修为、获取速率和下一境界需求。
3. 修为满足条件后可尝试突破。
4. 突破成功进入下一境界，并提高修炼效率。
5. 退出并再次进入后，按统一规则结算离线收益。

战力轴（ADR-0003，与修为轴同时结算）：

1. 玩家选定已解锁关卡，挂机时按公式自动战斗。
2. 战斗记录与掉落进入行囊。
3. 按境界穿戴装备、学习功法，提高战斗数。
4. 战力与境界足够后可挑战下一关，掉落更高品质装备与更高阶技能书。

## 当前必须具备

- 可配置的境界、关卡、怪物、装备、功法与修炼/战斗数值。
- 可靠的本地存档、备份、v1→v2 迁移。
- 离线时间与一次结算（修为 + 历练）。
- 竖屏底栏：修炼、历练、行囊、功法、设置。
- Android 开发包的可重复构建。
- 为内容包和 APK 两层更新预留明确接口。

## 明确不做

- 账号、云存档、排行榜、聊天、宗门多人玩法。
- 付费、广告、正式运营后台。
- 服务器真挂机、论剑、炼器重铸、多套装配、视觉战斗。
- 正式美术、批量剧情、配音和复杂动画。
- iOS 发布、应用商店接入和自动线上发布。

## 产品变更门槛

任何新增系统先说明其对核心闭环、存档格式、更新包、测试和工期的影响。若改变以上边界，必须由项目负责人确认并新增或更新 ADR。
