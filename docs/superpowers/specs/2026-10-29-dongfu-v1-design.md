# 洞府 v1 设计（药园 / 炼丹 / 强化）

日期：2026-10-29  
状态：成鹏确认先出方案、细节后按真机效果再改  
范围：洞府总览 + 药园 + 炼丹 + 强化入口

## 目标

洞府是底栏经营页。v1 只做三块设施，把挂机材料与时间转成草药、丹药，并承接现有装备强化。服务器权威结算，支持离线成熟/炼成后领取。

## 总览

- 入口：底栏「洞府」（替换当前占位页）。
- 三个设施卡片：药园、炼丹、强化；展示进行中数量与可领取红点。
- 洞府等级：v1 不做数值解锁树；如需展示可只做装饰级，不影响产能。

## 药园

- 固定地块数（建议默认 4，后台可配）。
- 流程：选种子 → 种植 → 服务器记录成熟时间 → 成熟后领取草药入背包。
- 种子来源：关卡掉落 + 少量商店/初始赠送（具体表后配）。
- 支持一键领取全部成熟地块。
- 加速：v1 可不做；若做则消耗灵石，数值后配。

## 炼丹

- 流程：选配方 → 扣材料（草药 ± 灵石）→ 进入炼制队列 → 到时领取丹药。
- 队列长度建议 1～2（后台可配）。
- 配方 v1 先 2～3 个，例如：修为丹、攻击临时丹、防御临时丹（名称与数值后配）。
- 成功率：v1 默认必成，不做爆炉。
- 丹药使用：修为丹加修为或短时加快修炼；临时属性丹在战斗结算中生效（时长后配）。

## 强化

- **不新建强化规则**。复用现有炼器精粹分解/强化模型与后台配置。
- 洞府提供强化入口，UI 可复用行囊强化面板。
- 分解入口仍在行囊；洞府侧重强化与领取经营产出。

## 数据与结算

- 种植、炼丹队列存服务器；登录/打开洞府时按统一时间结算可领取状态。
- 产出进背包；背包满时的策略：提示清理或暂存（实现时选一种写死，优先提示去分解/使用）。
- 后台需可配：地块数、种子、配方、队列长度、丹药效果字段。

## 明确不做（v1）

藏经阁、器室炼新装、门派、灵兽、洞府装扮、真 3D 场景、技能树、炼丹失败学。

## 与其它线的关系

- 「更多自动技能 + 技能/装备特效 + 分层换装」可并行排期，不阻塞洞府 v1 闭环。
- 功法页半残：洞府 v1 不依赖功法；功法改技能/门派另案。

## 验收

1. 能打开洞府总览并进入三个设施。  
2. 能种植并收获至少一种草药。  
3. 能用草药炼成丹药并使用，角色侧有可见效果（修为或临时属性）。  
4. 能在洞府入口完成一次现有规则下的装备强化。

## 迭代方式

先按本方案做出可玩第一版；成鹏按效果提修改，再改数值与交互细节。
