# v14：滚动顺滑 + Q 版物品详情弹窗 + 物品说明文案 + 历练挂机打小怪特效

分支 proto/week1，基于 0.13.1 (34) 62a8664。只做了本地提交，没有推送，也没有发版。

## 1. 滚动（393d407）
**原因**
- 物品格、关卡卡、面板都会拦截鼠标或触摸事件（MOUSE_FILTER_STOP），手指按在它们上面拖时，事件到不了 ScrollContainer。另外 Godot 自带的触摸拖动只在 `is_touchscreen_available()` 时生效。所以背包“经常滚不动”，历练列表也不跟手。
- 心跳（约 12 秒一次）每次都把背包格子、纸娃娃、关卡列表（横排会跳回开头）、功法页、突破页整页重建，每次卡 0.65–0.75 秒，正在拖的手势也被打断。
- 历练页本波圆点每帧都新建 StyleBox，导致整页每帧重绘。
- 默认主题的滚动条是可见的，物品格还带 tooltip，触屏上会弹出悬停提示。

**改动**
- 新增 `ScrollKit`：全局给每个 ScrollContainer 挂上，滚动条一律不显示（主题样式置空，再加 SHOW_NEVER）。
  - 自己处理手指拖动和惯性：死区 18 px、只认自己方向的拖动，嵌套滚动区之间按方向区分谁接手。
  - 拖动开始后，对按钮发 SCROLL_BEGIN，取消它的按下状态，所以拖动不会触发点击。惯性滑动中按下会先停住，也不触发点击。
- 背包、历练、功法、突破四个页面在心跳时先比较内容签名，没变就不重建。圆点样式只建一次。物品格去掉 tooltip。

## 2. 物品详情弹窗（70a5809）
- 场景 `scenes/ui/item_detail_popup.tscn`（`ItemDetailPopup`），位置、字号、颜色都集中在 `LAYOUT` / `COLORS` 里。数据由 `ItemDetailView` 从背包模型和配置算出来，没有假数据。
- 四种版式，按设计稿 q_popup_*：
  - 装备（背包里，身上同部位有装备时显示属性对比，±差值带绿色上箭头或红色下箭头，差值按显示出来的取整数值计算）
  - 已穿戴
  - 功法书
  - 材料
- 按钮都走原来的流程：穿戴、卸下、换一件（打开该部位的选择列表）、强化、一键强化、突破、分解（二次确认）、使用（功法书）。材料按设计稿是「确定」。
- 切图：arrow_down_red、chip_purple、row_gold_74、icon_enhance_exp(@2x)。install_q_art.py 增加了弹窗切图检查，授权表也加了对应行。

## 3. 物品说明文案（1180e76 + dev2 数据库已直接修正）
- 突破石说明去掉了“（起始值，可在后台修改）”。功法书补了默认说明。种子数据和迁移 0023 都已改。迁移可以重复执行，只改说明字段，后台改过的不会被覆盖。
- `/content/current` 现在下发物品的 description。原来不下发，所以客户端永远看不到物品说明。新后端部署后，手机上才能看到说明。

## 4. 历练挂机打小怪特效（anim_q/battle_idle，动画交付 README 的 5 步）
- 旧的目标怪图隐藏，只用它取贴图和翻转方向。原来 (470,600) 的装饰飞剑去掉，改用特效里自带的飞剑。主角绑定到 `bind_hero`。
- 特效节点加在怪物名牌和血条**之前**，所以名牌和血条永远画在特效上面。
- 怪物气血用配置值 wave.monster.hp。伤害数字按血条掉下去的部分计算，加起来正好等于气血。
- 删掉了页面原来的 `_float_gain`，「+N 修为」只由特效飘一次。
- 怪物溶解到下一只刷出之前，血条先藏起来（用 `monster_showing()` 判断）。
- 掉落只传这次结算真正进了背包的物品（`lastSettle.drops`，不含背包满没拿到的、自动分解的），而且只在历练页可见时才传。终点是底栏「背包」文字的位置。掉落节点层级是 50，高于底栏的 30。
