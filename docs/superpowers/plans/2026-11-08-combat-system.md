# Unified server-authoritative combat implementation plan

Goal: extend existing simulateBattle and play its complete server timeline in a shared independent battle page for stages and fog.

Architecture: Keep hitDamage and running-skill rotation. Add optional critical/dodge/status/rage parameters with deterministic injectable rolls. Keep legacy simulateBossFight compatibility for existing tests and tooling; live routes use simulateBattle. Subclass BattlePage for timeline playback so UI-owned layout stays untouched. Store committed results server-side before playback and expose recovery; retreat is an explicit failed battle without win grants.

Constraints: local worktree proto/combat-system; no stage_page/home_page/BattlePage layout edits; no cave changes; no APK/latest/deployment; no merge. Fog retains position/revealed cells and separate enemy/loot/time-limit config. Gate progression stays P1.
