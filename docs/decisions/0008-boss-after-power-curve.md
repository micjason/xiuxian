# ADR-0008：首领战力等成长曲线算完再定

- 状态：已接受
- 日期：2026-10-13
- 决策者：项目负责人
- 相关：`docs/superpowers/specs/2026-10-12-numeric-scheme-design.md`

## 背景

首领如果按「已经发布的装备和功法加总，再取百分比」来定，以后每多发一件更强的同部位装备，已经调好的首领都会跟着变。装备从十几件增到几十件时，这套数很难维护。

战斗公式、战力公式、标准角色的算法仍用数值方案一。本决策只定首领数值的填写顺序。

## 决策

1. 首领战力不从已发布物品和功法的清单加总得来。
2. 填写顺序固定为三步：
   - 先设好境界成长、装备、功法、掉落几率。
   - 再估算正常玩家到达各档战力要多久。掉落有随机，这个时间取大致的预期，不取最快或最慢。
   - 最后把首领放在对应时间点的战力上。玩家以正常的属性比例养到这个战力，就应当能打过。
3. 正常有多强，仍用数值方案一的标准角色来估：该境界的基础，加上这一阶正常能拿到的装备和正在运转的功法。难度可以分成几档，每一档是这条曲线上的一个台阶。
4. 同一阶再增加装备或功法时，只要没有改变「到这个时间点的正常战力」，已定下的首领不动。
5. 只有两种情况改首领：到达该时间点的正常战力变了，或故意改这一关的目标时长。
6. 属性比例和标准角色差得太开时，不保证战力数字到了就能赢。验收仍沿用数值方案：比例差在 30% 以内时，战力高 5% 以上应赢，低 5% 以上应输。

## 备选方案

- 用已发布内容的理论最高战力，再取 30%、60%、90% 当三档首领。目录一变，首领就变，因此不采用。
- 在掉落几率还没填完时，就把首领按标准角色定成最终数值。若玩家到点时凑不齐那套装备，目标时长和首领会对不上，因此首领的最终数值等成长曲线算完再填。

## 后果

### 正面

- 同阶多做装备，只增加选择，不推动首领。
- 首领表达的是「玩到这里应该有多强」，物品清单和关卡难度分开维护。

### 代价与风险

- 装备、功法、掉落没填完之前，库里的首领只是草稿，不能当成最终关卡。
- 时间是预期值。掉落偏斜时，一部分玩家会早于或晚于这个时间打过。

## 验证与回滚

- 成长内容填完后，估出到达某档战力的时间，把首领设在该战力上，再用正常配装的人偶核对能否打过。
- 若正常配装在目标时间附近仍打不过，或远早于目标时间就打过，复审这一档的掉落或首领，不改战斗公式。

- 数值方案一：标准角色、难度系数、修炼时间、掉落。
