# 历练循环（战斗 / 行囊 / 装备 / 功法 / 设置）

2026-10-02 起，服务器和账号以 [ADR-0006](../decisions/0006-online-product.md) 为准。下文的「非目标」描述的是这条循环当时没做的内容。

依据 `docs/research/idle-xiuxian-systems-2026-09-10.md`、ADR-0003、ADR-0004 与 ADR-0005。不抄竞品名称与数值。当前事实基线是 `0.1.15`、存档 schema 4；本篇定义的历练是长线战力轴，不因后续增加洞府与传承而废弃。

## 目标与非目标

目标：挂机修炼的同时挂机打怪；回来能在行囊核对收益、穿戴、学功法、突破，再挑战下一关。下一关掉更高品质装备和更高阶技能书。

本循环当时未做：服务器、排行、视觉战斗、多套装配、无限随机怪物种。服务器现已由 ADR-0006 纳入产品。定向器室只承接既有合阶、拆解、槽位胚子和一次性温养，不做无限随机重铸。

## 玩家可观察流程

1. 首次进入：凡人，第一关已选，行囊空，未穿戴，未学功法。
2. 停留或离开：修为按效率涨；当前关按战斗公式结算击杀与掉落。
3. 回来：一次弹窗写修为、击杀摘要、入袋物品；历练页有文字战报。
4. 行囊：上方是角色居中、五槽环绕的装备板；已穿装备只在板上，不进下方网格。网格按全部 / 装备 / 丹药 / 材料 / 功法分类。点槽位或格子弹出详情：攻、防、速、品质词条、装备战力，以及穿上后的人物战力变化。功法残页仍只在行囊参悟。
5. 功法：只有正在运转的功法生效，已学未运转作为图鉴。行囊残页先参悟入门；再交 2 本同名残页小成（技能属性 ×1.4）；详细规则见 `docs/design/five-hour-skills.md`。
6. 下一关除境界和战力外还有攻 / 防 / 速短板；缺哪条提示写哪条。每地有外围 / 深处 / 头目三层。
7. 够了则进入下一关，掉落表换成更高品质/更高阶。同阶穿 3 件伤害 ×1.06，穿 5 件伤害 ×1.12 且受伤 ×0.92。
8. 行囊满：按设置跳过掉落或丢掉未锁定的最低品质，并写进战报。丹药限时服用，材料温养一件未穿装备一次。

## 验收标准

- 在线每秒与离线区间用同一套战斗公式；重复打开不重复发同一段掉落。
- 时钟回拨：修为不减，不补发战斗。
- 离线超过上限：修为与战斗都只按上限秒数算。
- 白蓝紫金红装备都能掉、能显示、能穿；五槽互不覆盖错位。
- 黄玄地天功法都能学，高阶书有境界门槛。
- v1 旧档加载后修为境界不变，历练从第一关开始。
- 底栏五页都能进；设置能开关战报、改满包策略、导出存档。
- 原有前三阶突破与离线弹窗文案仍在。
- schema 3 旧档升级到 schema 4 后，已学功法保留且运转栏按温和补位规则初始化。

## 状态与公式

配置进 `game/resources/config/adventure.json`，不进存档。

```text
战斗数 = 境界基础 + 已穿装备（含合阶与温养） + 正在运转的功法（入门/小成） + 套装与养体丹
装备属性 = 表内攻防速血 × (1 + 0.12 × 合阶)
有效伤害 = max(1, 攻 × 套装伤害倍率 - 敌防 × 0.4)
敌有效伤害 = max(0, 敌攻 - 防 × 0.5) × 套装受伤倍率
击杀耗时 = 敌血 / (有效伤害 / 攻击间隔)
阵亡耗时 = 无限（敌有效伤害=0）或 己血 / (敌有效伤害 / 敌间隔)
若 阵亡耗时 ≤ 击杀耗时：本段 0 击杀，记「不敌」
否则 击杀数 = floor(秒数 / (击杀耗时 + 重生间隔))
战力 = 攻 + 防 × 0.8 + 速 × 1.5 + 血 × 0.04
装备战力 = 同式，只算这一件
攻击间隔 = max(0.7, 境界间隔 × 100 / (100 + 速))
深处/头目怪倍率 1.35 / 1.6；掉落再 × (1 + 0.25 × 层)
```

掉落用存档里的 `loot_seed` 做可重复伪随机，不读系统时钟。表内 `loot_chance_scale`（当前 0.2）乘在每条掉落概率上，用来把满包从「十几分钟必炸」收成「回来整理一次」。

满包策略：

- `skip`：不进袋，计数到 `bag_skipped`
- `discard_lowest`：丢未锁定、未穿戴的最低品质 1 件再进袋；没有可丢则等同 skip

## 存档（当前 schema 4）

schema 3 在原有修为三字段上增加：行囊（含合阶与温养）、容量、下一 uid、穿戴 uid、已学功法与等阶、当前关与层、已解锁关、各地斩杀、丹药时效、战报、`loot_seed`、设置。schema 4 再增加运转中的心法 id 与战技 id 列表。界面滚动位置不存。迁移链保持 `v1 → v2 → v3 → v4`。

ADR-0005 的计划 schema 5 会增加经营资源、队列、保底、见闻纪事、受保护溢出和传承状态；不能删除或重算 schema 4 的装备、功法、地点与随机种子。

## 明确不做

当前五小时历练不做自动突破、自动穿戴、自动学功法、商店买格、套装收集进度、无限层塔、日次数。长线设施和传承按 `docs/design/long-term-progression.md` 分里程碑开放。排行和斗法不在第一版，见 ADR-0006。

## 长线供需接口

- 历练从 Day 7 起可投放药材和灵石，从 Day 30 起投放矿材、兽材与定向保底进度；未开放用途前不大量掉落。
- 头目首胜和累计击杀提供确定性建设量，随机掉落只加速，不作为经营或主线唯一门票。
- 重复装备在穿戴、合阶和拆解之间选择；残页在入门、小成和藏经阁研修之间选择。
- 洞府产出的丹药、槽位胚子与研修进度必须回到当前修炼或战斗短板，不能形成独立“洞府战力”。
- Day 30 的远行不得让同一角色同时领取两份完整战斗收益；所有收益继续共用 `TimeService` 的一次离线结算。
