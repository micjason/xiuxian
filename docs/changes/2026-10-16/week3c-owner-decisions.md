# 第 3c 周：掉率 5%、突破石 2 倍、每天 5 次重复奖励（2026-10-16，第二次决定）

分支 proto/week1，本地，未推送。

## 做了什么
1. **普通怪每击杀掉率 4% → 5%**：种子 `prototype-v12.ts`（`monsterDrop.chanceBp` 400→500）、后台新建关卡的默认值（5）、迁移 0022（只改还是 400 的关卡，后台改过的不动）、测试（单元：499 掉/500 不掉、20 万次抽样 ≈ 5%；e2e 同；参考配置每小时件数按 5% 重算为 36–45 的断言区间）。
2. **重复挑战突破石概率为最初值的 2 倍**：下品 70%、中品 30%（种子 5250→7000、2250→3000；迁移 0022 只改还停在 0021 写入的 5250/2250 的条目）。数量不变（下品 1–2、中品 1）。后台首领编辑器可改，上限 100%。
3. **每日重复奖励次数 3 → 5**：`bossDailyRewardCount` 默认值（代码、后台表单默认、种子），迁移 0022 只改全局里还是 3 的。后台「战斗公式与参数」可改。
4. 满包规则：按已实现的保留。顺带把提示文案对齐设计表 v1.3：弹窗「背包已满（20/20）／新掉落的装备没能入包」，结果页提示「背包已满，新掉落的装备没能入包」（去掉了"请先分解装备"，弹窗仍带"去背包"按钮）。
5. 新增迁移测试 `src/db/migration-0022.test.ts`（种子默认值；只改旧默认值、不碰后台改过的值、可重复执行）。
