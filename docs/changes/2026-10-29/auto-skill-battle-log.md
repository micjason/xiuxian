# 2026-10-29 首领战报记下自动技能

挑战、自动挑战、挂机首领都走 `fightStageBoss`。以前 `ultOf()` 固定为空，战报没有施放。

- 只记正在运转、栏位仍开放、没有停用的自动 / 被动技能。已学未运转的不记。
- 第 1、5、9… 次普攻之后，按栏位轮流追加一次与当次普攻相同的伤害。没有运转技能时，胜负和日志与以前逐项相同。
- 日志事件：`kind: "ult"`（协议字段，界面不展示这个词）、`name`、`skillSlug`、`fxType` / `fx`、`castMode`。`ultCasts` 同步这些施放。
- 玩家看到的名字是技能显示名。空名，或配置仍写成「大招 / 暴击」时，写成「自动技能」。
- 不增加冷却条、充能圆盘、手动释放或自动战斗开关。客户端预演用同一套出手节奏，方便战报和特效对上服务器。
