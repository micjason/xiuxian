# 后台战斗预览草稿

老板已批准素材整理、战斗预演两张主稿。本页只看表现，不接入游戏。

## 决定

- 页面仍在「游戏配置 / 战斗动画」。两种模式共用同一份内存数据，切换不另存一份。
- 持久化只用新表 `battle_preview_drafts` 和目录 `BATTLE_PREVIEW_DIR`（默认 `backend/var/battle-preview-drafts`）。
- 不写 `animation_packs`、内容草稿、发布快照、玩家进度。没有发布、上线、同步到游戏。
- 抽帧仍只收 PNG，或一段 8 秒以内的 mp4 / webm / mov。新帧时长用现有的 83 毫秒，可改范围仍是 30 到 400。
- 一帧只有一个动作。隐藏帧留在胶片上，不参加播放和预演。
- 飞出物、打中爆开可以没有，预演跳过并写明。
- 竖屏框用游戏画布 1080×2340。脚底按 `combat_cast.gd`：宽的 23% 与 77%，高度 1280。不采用示意图上的 9:16。
- 演示数字只显示草稿里的文字，默认 `123`，不计算伤害。

## 不做

- 不改 Godot 战斗，不读、不写游戏动画资源。
- 不做技能、连击、镜头、音效，也不做发布。
